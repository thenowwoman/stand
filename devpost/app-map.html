Stand App Map

A compact reference for the current proof-of-concept: a mobile-first profile builder that turns a vague skill description into structured services and opportunity ideas.

What the app does

The app accepts a short text prompt, extracts likely skills, turns those into pricing-friendly service packages, and shows a client-ready profile plus a short opportunity list. It keeps the profile in localStorage so a user can return without an account.

Reference route

  1. Start here: src/App.tsx — the main app flow, prompt state, generated skill/service data, and persisted browser state.
  2. Core logic: generateFromPrompt() in src/App.tsx — turns the freeform description into structured outputs using keyword matching and seeded profile data.
  3. Visible output: src/styles.css — mobile-first cards, service package styling, and the profile/opportunity panels the user sees.

To change this, start here

  • Change the prompt behavior: edit the textarea and submit logic in src/App.tsx.
  • Change the generated skill/service suggestions: adjust the skill catalog and service list inside generateFromPrompt().
  • Change the visual feel: update the card layout and spacing in src/styles.css.

Practice to reuse

This project shows a useful pattern: when a requirement starts vague, define an observable result early and test it in the browser. The app’s core acceptance criterion is “a short description turns into a credible client-ready profile,” and it is validated by the actual build and a browser check rather than just a code review. The same approach can help on other projects: write the user-visible result first, then build only the logic needed to satisfy it.
